<header class="page-mast">
  <div class="mast-title"><h1>About the project</h1></div>
  <div class="mast-copy"><p class="page-deck"><strong>wp_pivot_flutter</strong> began in 2020 as a Flutter implementation of the Windows Phone Pivot control. It now pairs implementation work with published evidence.</p></div>
</header>

<section class="manual-section" aria-labelledby="current-title">
  <header class="section-label"><h2 id="current-title">What exists</h2></header>
  <div class="section-body">
    <p>Version 2.2.0 includes <code>WpPivotView</code>, configurable motion, gesture handling, and the OFL-licensed Selawik fallback. The first Pivot study compares it with WP8.1 emulator recordings.</p>
    <p>An opt-in library adds six experimental controls. Slider, ProgressBar, and TiltEffect have a <a href="{{ '/research/components/micro-controls/' | relative_url }}">held-out comparison study</a>; the earlier three controls and their limits remain in the <a href="{{ '/research/components/' | relative_url }}">component index</a>.</p>
  </div>
</section>

<section class="manual-section" aria-labelledby="scope-title">
  <header class="section-label"><h2 id="scope-title">Boundary</h2></header>
  <div class="section-body"><p>The project studies layout, typography, color, and motion. It does not redistribute proprietary Microsoft fonts or artwork. Lumia validation remains separate from emulator findings.</p></div>
</section>
